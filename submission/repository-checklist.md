# Public repository checklist

- [ ] Repository is public and created within the hackathon window
- [x] Root `LICENSE` contains full Apache License 2.0 text
- [ ] Repository About section shows Apache-2.0
- [x] English README explains replay, artifacts, testing, security, and limitations
- [x] Pre-existing related project is disclosed
- [x] Synthetic data and recorded context are labeled
- [x] No key is required and `.env` is ignored
- [x] Example outputs and actual test/dbt reports are committed
- [x] Final screenshots are generated and linked locally
- [ ] Final screenshots are included in the publication commit
- [ ] Public demo URL works without an account
- [ ] Public under-three-minute video works and has captions
- [x] Local high-confidence secret scan passes
- [x] Local dependency vulnerability and license metadata audits pass
- [ ] Audits are re-run and reviewed on the publication commit
- [ ] Placeholder URLs and commit hash are replaced in the manifest
- [ ] Devpost description matches actual live/replay status

Publication and submission remain user-controlled actions.
