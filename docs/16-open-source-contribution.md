# Proposed DataHub Skills contribution

`contrib/datahub-skill` contains a proposal named `datahub-schema-migration-impact`. It follows the current official Skills frontmatter and workflow style observed in the installed DataHub Skills 1.4.1 package.

The skill fills a focused gap: combine search, schema comparison, downstream lineage, query context, ownership enrichment, evidence coverage, and a migration checklist while forbidding mutation before approval. It complements general search, lineage, quality, and enrich skills rather than replacing them.

Included files are the skill definition, a synthetic incident, sample output, README/rationale, and a structural validation test. The contribution was prepared and validated locally only. No DataHub pull request, issue, or upstream claim has been made; submitting upstream requires explicit user approval and a fresh review of the official contribution guide.
